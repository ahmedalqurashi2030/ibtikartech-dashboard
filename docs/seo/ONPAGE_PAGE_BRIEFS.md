# Ibtikar Tech — On-Page SEO Page Briefs

Status: v0.1 — implementation briefs for existing pages
Market: Saudi Arabia first, Gulf second
Research snapshot: 2026-09-18
Depends on: `INDEXATION_MAP.md`, `KEYWORD_INTENT_MAP.md`

> These briefs define intent ownership before copy changes. Quantitative keyword metrics remain pending Semrush API units. Pages marked as gaps/candidates are not created in this stage.

## Shared on-page rules

- One clear primary intent per URL.
- Title, H1, introduction, body sections, internal links, and CTA must describe the same service intent.
- Keep Arabic natural; do not repeat the exact keyword mechanically.
- Platform names are modifiers, not separate pages by default.
- Preserve current UX structure, visual identity, and conversion flows unless a specific SEO issue requires a structural change.
- Do not add unsupported claims, guarantees, fake numbers, or location claims.
- Use Saudi-market wording where relevant, but do not create thin city pages.
- Informational articles support commercial pages; they do not replace them.
